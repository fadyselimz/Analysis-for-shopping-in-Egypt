##Egyptian Retail Market Analysis
Overview

This project was developed as a graduation project for the Egyptian Ministry of Communications and Information Technology (MCIT) Digital Egypt Pioneers Initiative (DEPI).

The project analyzes shopping behavior, customer trends, and retail patterns in Egypt using data analysis techniques and interactive visualizations to generate actionable business insights.

Objectives
Analyze consumer purchasing behavior in Egypt
Identify shopping trends and market patterns
Perform data cleaning and preprocessing
Generate visual dashboards and reports
Extract business insights to support decision-making
